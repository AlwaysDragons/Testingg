# Forge — training + recovery coach (iOS)

Native SwiftUI app that combines **Hevy workouts** + **Apple Health** to optimize muscle growth, plans your
**OneLife Fitness** recovery (sauna, cold plunge, hot tub, HydroMassage, compression sleeves), and lets an
**AI coach (Claude)** analyze everything.

| Tab | What it does |
|---|---|
| **Today** | Readiness score (HRV, resting HR, sleep, training load), today's OneLife protocol, AI brief, key stats, weekly volume, recent PRs |
| **Training** | Weekly hard sets per muscle vs. the 10–20 hypertrophy target, stalled lifts, e1RM charts per lift, full workout history |
| **Recovery** | 7-day plan: which days for sauna / cold plunge / hot tub / HydroMassage / compression, with doses and the reasons why |
| **Coach** | Chat with Claude using all your data (90-day log, 30-day health, analysis, plan). One-tap prompts |
| **Settings** | API keys (stored in Keychain), sync, training days, which amenities your club has, units |

Opens with sample data so you can see everything before connecting keys.

## Install on your iPhone (free Apple ID, Intel Mac)

**Requirements**
- Mac on **macOS 15 Sequoia or newer** (Apple menu → About This Mac). Sequoia runs on MacBook Pro 2018+, Mac mini 2018+, iMac 2019+, MacBook Air 2020+.
- **Xcode** (free, Mac App Store). If your iPhone is on iOS 26, you need Xcode 26.
- iPhone + USB cable.

**Steps**
1. Get the code: `git clone <this repo>` then `cd Testingg/ios` (or download the ZIP from GitHub).
2. Generate the Xcode project (one time):
   ```bash
   /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"   # Homebrew, if you don't have it
   brew install xcodegen
   cd Testingg/ios && xcodegen
   open Forge.xcodeproj
   ```
3. Xcode → **Settings → Accounts → +** → sign in with your Apple ID.
4. Click the **Forge** project → target **Forge** → **Signing & Capabilities**:
   - Team: *Your Name (Personal Team)*
   - Bundle Identifier: change `com.yourname.forge` to something unique, e.g. `com.raoul.forge`.
5. On the iPhone: **Settings → Privacy & Security → Developer Mode → On** (it restarts).
6. Plug in the iPhone, select it at the top of Xcode, press **▶ Run**.
7. First launch only: iPhone **Settings → General → VPN & Device Management** → trust your Apple ID.

> With a free Apple ID the app expires after **7 days**. Just plug in and press ▶ again; your data stays cached.

## Connect your data

- **Hevy** (needs Hevy Pro): hevy.com → Settings → Developer → copy API key → paste in Forge Settings. Full history syncs; later syncs only fetch new workouts.
- **Apple Health**: Settings → *Connect Apple Health* → allow all. For HRV and resting HR you need an Apple Watch.
- **Claude**: console.anthropic.com → API Keys → paste. Pick Sonnet (balanced), Opus (deepest) or Haiku (cheapest).
  The big data context is prompt-cached, so follow-up questions cost much less. A full analysis costs a few cents.

## How the recovery plan works

- **Training days:** sauna after lifting (15–20 min); compression + HydroMassage for the lower back after legs; HydroMassage for the upper back after push/pull days.
  **No cold plunge within ~6 h after lifting**, because it blunts muscle growth.
- **Rest days:** contrast therapy (3 rounds of sauna then cold plunge, ending on cold), HydroMassage, evening hot tub. Compression too if the day before was legs.
- **Low readiness or short sleep:** evening hot tub 60–90 min before bed, and a lower-volume training suggestion.
- Training days are auto-detected from your Hevy history (or set manually). Each day's focus is predicted from your split rotation.

```
  project.yml            XcodeGen spec (HealthKit entitlement, Info.plist)

    Views/               SwiftUI screens + design system
```
